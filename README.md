# SHIFT LAB

대구의 공개 상가(상권)정보로 후보 지역의 업종 현황을 비교하고, 내가 넣은 비용 가정으로 필요한 자금을 따져 보는 개발판입니다.

**열기: https://tatao4503.github.io/shift-lab/**

## 할 수 있는 것

- 대구 행정동 150곳 가운데 세 곳, 상권업종 소분류 247개 가운데 두 업종을 골라 수록 점포 수를 비교합니다.
- 이전 기준일보다 얼마나 많고 적은지, 그 사이 목록에서 빠진 곳과 새로 수록된 곳이 몇인지 봅니다.
- 고른 동 안에서 점포가 어디에 모여 있는지 약 100m 격자 그림으로 봅니다.
- 보증금·월세 같은 비용을 직접 넣어 목표기간의 필요액과 예산 차이를 계산하고, A4 한 장의 검토안으로 냅니다.

## 알아둘 것

- 자료는 [공공데이터포털 소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)의 대구 파일을 행정동과 업종 소분류로 센 것입니다. 지금 자료의 기준일은 2026-09-30입니다.
- 점포 수는 수요·매출·성공 가능성을 뜻하지 않습니다. 목록에서 빠졌다는 것은 폐업이 아니고, 새로 수록됐다는 것은 개업이 아닙니다.
- 행정동은 실제 상권 경계가 아니며 면적과 인구가 서로 다릅니다.
- 비용은 사용자가 넣은 가정이며 실제 시세나 견적이 아닙니다. 넣은 값은 브라우저 밖으로 보내지 않습니다.
- 검토 방향을 정하는 규칙은 아직 검증하지 않았습니다. 창업 판단을 대신하지 않습니다.

이 저장소에는 화면을 띄우는 데 필요한 파일만 있습니다.
