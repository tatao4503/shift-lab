# SHIFT LAB

카페 자리를 두세 곳 알아본 사람이 계약하기 전에, 받아 둔 매물 견적을 같은 예산으로 비교하고 다시 확인할 것을 한 장으로 남기는 개발판입니다.

**열기: https://tatao4503.github.io/shift-lab/**

## 할 수 있는 것

- **매물 비용 비교.** 매물 두세 곳의 보증금·초기 투입액·월세·월 고정비를 넣어 같은 예산과 기간으로 얼마가 필요하고 얼마가 모자라는지 봅니다. 같은 행정동의 매물도 따로 넣습니다. 검토안은 A4 한 장으로 인쇄됩니다.
- **먼저 닫아 본 사람들의 경험.** 가게를 닫아 본 분들이 계약 전에 놓쳤다고 한 것을 적고, 업종별로 몇 명이 말했는지 세는 자리입니다. **실제로 모은 기록은 아직 없습니다.** ‘가상 예시 보기’의 숫자는 화면 확인용이며 실제로 누가 한 말이 아닙니다.
- **동네 점포 비교.** 대구 행정동 150곳 가운데 세 곳, 상권업종 소분류 247개 가운데 두 업종을 골라 수록 점포 수를 비교합니다. 이전 기준일보다 얼마나 많고 적은지, 그 사이 목록에서 빠진 곳과 새로 수록된 곳이 몇인지, 동 안에서 어디에 모여 있는지(약 100m 격자) 봅니다.

## 알아둘 것

- 점포 자료는 [공공데이터포털 소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)의 대구 파일을 행정동과 업종 소분류로 센 것입니다. 지금 자료의 기준일은 2026-09-30입니다.
- 점포 수는 수요·매출·성공 가능성을 뜻하지 않습니다. 목록에서 빠졌다는 것은 폐업이 아니고, 새로 수록됐다는 것은 개업이 아닙니다.
- 행정동은 실제 상권 경계가 아니며 면적과 인구가 서로 다릅니다.
- 비용은 사용자가 넣은 가정이며 실제 시세나 견적이 아닙니다. 매출은 예측하지 않고, 얼마가 드는지만 계산합니다.
- 경험 기록에는 이름·상호·주소·금액을 적을 자리가 없습니다. 화면에는 사람 수만 나오며 폐업의 원인이나 확률을 뜻하지 않습니다.
- 넣은 값과 기록은 브라우저 밖으로 보내지 않습니다. 파일로 저장해야 남습니다.
- 검토 방향을 정하는 규칙은 아직 검증하지 않았습니다. 창업 판단을 대신하지 않습니다.

이 저장소에는 화면을 띄우는 데 필요한 파일만 있습니다.
